# 半生 · 六个项目怎么选、怎么合

先写一句这镜结束时观众应当明白什么。人物的处境变了、两人的关系变了、还是交手双方换了先手？用最能讲清这个变化的项目当底稿。另一个项目只补一项缺口，例如手部表演、空间尺度或动作反馈。以下为根据源节点做的创作归纳，示例均为新写。

## 把两种写法装进同一场戏

| 想拍的变化 | 主次与分镜写法 | 拆开或放弃什么 |
| --- | --- | --- |
| 一人乘舟，一人决定留下 | 黑木崖「斩缆送舟」主写动作。缆绷紧，剑落，绳头回弹，船离岸。切《半生》式固定远景，沿用原来的岸线，两人之间的黑水越来越宽。距离本身交代了决定。 | 黑木崖静帧「雪舟诀别」已经离岸。选它作首帧，就从水面变宽写起。要拍斩缆，另备绳未断、舟仍靠岸的图。 |
| 失势的将领在殿门前等召 | 《奉天靖难》主写门内外的位置，利用阶差分出权位。借《大秦远征》的停笔反应，让门内书吏听见甲声时悬笔半拍，门外的人仍须等。 | 殿外远景看不到笔尖，笔留给内景。官服、书写工具与称谓另按本剧时代选。 |
| 主角到晚年仍认得那盏灯 | 《半生》主管前后机位；借《盛世长安》的旧物状态。年轻时两只手交接完整的灯，晚年在相同画面位置扶直歪掉的灯骨。灯骨的缺口在下一镜继续保留。 | 两次手势发生于不同年岁，各做首帧。街市密度和光线可以变，灯的朝向与人的眼线要接得上。 |
| 剑客从防守改为抢攻 | 黑木崖 V01-R02 主写针点剑侧、剑线偏移、红衣抢入与白衣回剑。借古风胶片的近景，只在对手回剑时让观众看见视线慢了半拍。 | 微距看针剑触点，半身看肩肘让路。重柔焦会吃掉银针；眼神和针尖分镜对焦。 |
| 多人围攻仍能认清局势 | 借《盛世长安》的群像分工在远景交代四路来人。黑木崖 K02/V02-R02 把这一轮收成两路剑锋夹一人，其余人留在已交代的画外方向。 | 广角负责站位，近景只跟当前攻守者。不能在近景里让四个人同时从同一侧抢入，或凭空换持剑人。 |
| 不露脸也看得出有人来袭 | 黑木崖 V15 以墙上的第二道剑影先通报危险，主角低身让剑、绕柱回击。若接权谋戏，可借《奉天靖难》的门框限住视野，把来者身份留到下一镜。 | 先定实物、光源、投影面三者位置。影子跟着真实兵器，柱边红幔仍是布，不多出一个红衣人。 |

## 遇到冲突时怎样落笔

- **空间与光色。** 宫墙的朱红可以铺满一面墙；黑木崖在 E01 把朱砂红收在柱边一幅薄绸上。前者让权力包围人，后者让视线跟随一个运动点。同一镜先选红色承担哪件事。灯市仍可保留原有多点暖光。
- **参考图分工。** 在素材说明里分别写谁定脸和衣服、谁补侧背面、谁定厅堂结构、谁只借衣袖动势。身份发生冲突，以本次指定的主资产为准。白底多角度卡的站姿、光线和背景仅在做资产卡时沿用。
- **静帧与视频。** 图片在最能读懂的瞬间停住。视频接续首帧已有的受力状态。黑木崖的多镜头 Seedance 稿可拆作攻防节拍；半生默认交付 Kling O3：每段据实际首帧另写一个主要事件，按现有六段式和连续时间轴输出。（增强版修订：用户选择Seedance 2.5或镜头符合 seedance-25.md 条件时，可保留多镜头攻防节拍，按Seedance六段格式输出。）
- **来源分量。** 黑木崖的两组测试废图、古风胶片的废片组供比较，分组名不能证明某个具体词导致失败。「宋式留白」在黑木崖是美术设定。时代、人物和原作剧情随本次故事重定。历史后缀、面板现值、本次建议分别记录。
