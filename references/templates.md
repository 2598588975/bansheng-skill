# 提示词组织与演示

本文件的演示是新写的模板与虚构情境，不能当成原项目原文或已生成素材。格式必须遵守format-contract.md；将模板变量换为当镜具体内容，保留全部必需项；原文只在source-prompts.md。

## 图片提示词结构

```text
16:9横画幅，[景别与机位]。[年龄与身份的角色]，[稳定的脸部、发式、衣服和手持道具]，[当下静态瞬间]。人物位于[位置]，[前中后景和负空间关系]。[具体时代取向的空间、季节与天气]。[实际光源方向]，[主色与少量点缀色]，[明暗关系]。真人实拍质感的中国古代历史电影剧照，[浅景深或深焦等一致的摄影关系]。[当镜可见的2–3项实体材质]，克制胶片颗粒。--ar 16:9 --v 8.2 --raw --s 50 --chaos 0
```

如果要文字留白，只写负空间用途；清晰书法、印章和字幕通常后期添加。没有封面需求时，不给每镜留同样的大块文字区域。

## 已选图片的编辑提示词结构

```text
只修改[一个明确问题及目标状态]。保留原图的[可见脸部特征]、[构图与机位]、[服饰与道具]、[背景布局]及[光源/色调]。不要改变[本次最易误改的两项]。
```

编辑时通过用户界面的参考图/编辑入口提供实际原图；“保留原图”这句话本身不建立图片引用。

## Kling O3六段式结构

```text
主体：继承首帧中[可见人物/姿态/脸部/服饰/道具及位置]；[唯一主动作]，保持[关键身份与结构]。

场景：延续首帧的[实际空间与背景]，[环境微动的方向、速度及程度]；[固定物体]保持稳定。

拍摄风格：[T]秒单镜头，真人实拍质感的古代历史电影。[一个主导运镜]，焦点保持在[主体]，景深、运动模糊与胶片颗粒克制可信。

光影构图：继承[图中光源及方向]、[主色/点缀色]，保持[受光与暗部的具体材质]；[脸/手/道具]完整留在[图中相应位置]。

情节：0.00–[第一终点]秒：[首帧状态]；[下一起点]–[下一终点]秒：[主要动作及表演]；[最后起点]–[T]秒：[可剪落点]。声音：[人物台词或画外音的区别、环境音]。

否定控制：[该镜对应的脸/手/道具/空间/天气失误]；无字幕、无Logo和水印，不生成BGM。
```

按实际秒数生成连续时序。变量不是平台语法，不得把`[T]`或方括号说明直接给用户当成可执行提示词。

## 条件演示：S03已选图片符合上述可见内容时

以下仍是条件示例。只有实际查看图片确认脸、衣服、信囊、姿态、村门和光源都对应后，才可作为最终版。

```text
主体：继承首帧中花白须发老人的长椭圆脸、眉间小痣、直鼻梁、灰褐色粗麻衣领及胸前左手托着的褪红色布信囊。保持身体和持信囊手势基本稳定，主要动作是目光从信囊移向前方，嘴角渐生一丝克制的笑意。

场景：延续雨中的旧木村门与柔和虚化背景。细雨从上方略向右下飘落，衣袖水珠沿布纹自然下滑；背景门框与远处暖灯的位置保持不变。

拍摄风格：5秒单镜头，真人实拍质感的古代历史电影。摄影机开头稳定，随后极缓慢向前微推，始终保留胸前信囊，焦点锁定老人的眼睛；浅景深、细微运动模糊与胶片颗粒自然克制。

光影构图：继承左上方冷青灰漫射天光与远处小面积暖灯光点。老人位于画面右侧，暗部保留须发、皱纹与湿麻布纹理，左手、信囊和双眼始终完整在画面内。

情节：0.00–0.50秒：建立首帧状态，老人低目看着信囊，只有自然呼吸和雨水微动；0.50–2.50秒：老人缓慢抬眼看向前方村门，头部仅轻微上抬；2.50–4.00秒：眼神逐渐柔和，嘴角浮现淡淡笑意，左手轻轻收紧信囊；4.00–5.00秒：笑意收住，视线安静停在前方，镜头稳定结束，保留可剪尾帧。声音：仅有细雨、湿衣摩擦和一次轻微呼吸声，人物不说话。

否定控制：不换脸、不变年轻，不改变小痣位置、须发、衣色和信囊颜色；手指不融合，不新增道具或人物，村门不漂移；无夸张哭笑和大幅度转头，无假雨水和塑料皮肤；无字幕、无Logo和水印，不生成BGM。
```

参数与操作交接：选择Kling O3→图生视频，上传实际S03单图到首帧位置，粘贴以上提示词，设置16:9、5秒、单镜头；若无5秒选项，先按可用时长重写时间轴再提交。声音开关按环境音需要设置，无音频入口则把三种声音留到后期。用户自行点击生成并检查首帧、手/信囊、抬眼、微笑和尾帧。
