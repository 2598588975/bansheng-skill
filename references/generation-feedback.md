# 成片回填记录

用户回传生成的图片、视频、截图或失败描述后使用。目的：把每镜“哪组设置好用、失败在哪、下次只改什么”记下来，下一镜/下一集不从头试。思路借自乱霞号的生成后回填，按半生的MJ＋Kling O3／Seedance 2.5流程改写。

## 硬规则

- **证据等级分开标注，不混用**：
  - 文字成稿：只有提示词，尚未生成。写了某效果不等于出现了。
  - 已生成未审看：用户说生成了，但没发回媒体。
  - 用户反馈：用户描述了结果，本技能未独立看片/看图。
  - 已实际查看：本轮实际看过图片或视频（截图只能核验该瞬间的外观与构图，不能证明速度、接戏、声画同步）。
- 不声称未看到的效果；不凭提示词难度推测成功率；一次生成内的多帧不算多次独立样本。
- 一次只改一个主要变量，保留已成功的部分。连续两次同方向修正无效时换方法（拆镜、换首帧、换平台），不叠加更长的禁止词。
- 记录不改写原文底版和本技能规则；只有用户要求维护技能且有重复证据时，才把失败模式回补方法文件，并保留条件与日期。

## 保存位置

与查库缓存同处：用户工作文件夹或本轮输出中的`项目名-feedback.md`。用户没有保存位置时，在回复中给出可复制的记录，不为建记录阻塞修改提示词。用户只要修改后的提示词时可省略展示。

## 每镜记录模板

~~~text
镜号与版本：S03-v02
阶段：图片 / 视频
平台与模型：MJ V8.2 / LibTV Style Image V8.2 / Kling O3 / Seedance 2.5（入口：即梦/LibTV/其他；未知写未知）
实际使用设置：画幅、风格化/怪异度/多样性；或时长、清晰度、参考素材清单、声音开关、首帧槽位（只写用户确认或看到的值，未知写未知）
证据等级：文字成稿 / 已生成未审看 / 用户反馈 / 已实际查看（附文件名与观察区间）
有效之处：哪些锚点、动作、光色、构图做到了（逐项：出现 / 部分出现 / 未出现 / 出现但错误 / 无法判断）
观察到的失败：具体时间区间或画面位置＋实际发生了什么
诊断：文本矛盾 / 首帧或参考冲突 / 时长与对白容量 / 动作过密 / 生成波动；已排除与未排除的原因
下一版只改：一个变量（例如：减为一个主要事件；把@Image2职责缩为场景空间；怪异度50→0）
保持不变：已成功的设置与段落
~~~

## 项目汇总（可选）

同一项目积累数镜后，按“平台/模型＋入口＋主要设置”分组汇总“命中数/可判断样本数”，用户反馈与已实际查看分列。样本少时只写“仅该样本观察”，不建立排名。下一集开拍前先读此汇总与角色锚点卡。
