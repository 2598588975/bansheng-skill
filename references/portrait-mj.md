# 人物优先·古风胶片

这是对《中式美学丨古风胶片》原文与少量可见样图的创作归纳。主要依据“测试丨确定组”，证据与例外见 [portrait-source-index.md](portrait-source-index.md)。它是半生的并列视觉分支，沿用 [format-contract.md](format-contract.md) 的中文单段、八项顺序和逐镜五项设置，不替换原版，也不把来源英文原文强制改成中文。

## 先分清两种重心

| 维度 | 原版：人物＋场景·人生叙事 | 本分支：人物优先·古风胶片 |
| --- | --- | --- |
| 起点 | 人生处境、事件变化、空间与人物的关系 | 此刻是谁、目光落向谁/什么、手与道具是什么关系 |
| 镜头组织 | 建立空间、行为中景、面孔、器物之间形成节奏 | 先确定人物锚点；单人、双人、人物与动物或道具的瞬间 |
| 背景任务 | 可以独立叙事，宫阙、长街、战场、寒江可成为主体 | 提供框景、纵深、色块、光源与处境线索，注意力回到人物 |
| 质感侧重 | 实体材质、风霜、身体重量；原库常有65mm胶片气质 | 35mm胶片气质、低反差柔焦、柔和高光晕染、轻抬黑位；脸与关系仍可辨 |
| 情绪承载 | 人生前后对照、意气与风霜，也可平静温暖 | 眼神、嘴唇、侧脸、湿发、手势、衣袖及人物距离 |
| 适用任务 | 故事分镜、空间交代、历史人物经历 | 人物主视觉、近景古风、亲密关系、克制武侠与东方幻想人物 |

差别是注意力分配，不是互斥题材：原版也有特写，本版也有中远景和双人。用户要求宏大空间时用原版；一组镜头可标明哪些沿用原版、哪些用本版，统一时代、人物、色彩与服装后组合。不要给每镜自动混入两套大画幅、胶片和锐度术语。

## 深层结构：可变人物块＋统一成像块

来源常把两块文字连接：前半段明确人物身份、衣着、手势、道具方向、人物位置和景别；后半段重复35mm、青绿空气、低反差、柔焦、微量高光晕染、浅景深、细颗粒和写实东方气氛。有效迁移是保留这些功能关系，再替换人物与故事，不是仅换角色名或堆“仙气”“高级”“8K”。

新作写作前在内部确定三件事：

1. **人物这一刻的行为意图**：等人、掩护、试探、照料、警觉、决断等；转成静帧可见的目光与触点。
2. **画面的主视觉关系**：例如眼睛在近处剑锋之后、手护住灯、两张侧脸围绕一枚发簪。一个关系足够，次要道具不抢它。
3. **一个有来源的用光方案**：窗光、暮光、月光配灯、檐下天光等。统一冷暖、表面反射和背景退隐。

生成时仍依半生八项顺序输出。画幅/景别先行，人物块占主要信息；场景不删掉，而是压缩成能够解释人物的空间。参考原文时按任务取2–3个节点，不把整库重复风格尾巴全拼到一镜。

## 十条可迁移判断

### 1. 脸的个体性先于“美女/侠客”标签

用年龄阶段、两三个稳定面部特征、发式、衣领与衣色建立人；随后是眼线、嘴唇状态和身体朝向。来源大量写young East Asian woman只是示例群体，不把年轻女性、美貌、红白配色设成所有作品必需条件。男性、年长人物与普通人也能使用本分支。不同镜头复用角色锚点，文本不承诺锁脸。

### 2. 静止姿态要包含关系

用“左手托住狐狸前腿，右手贴着颈侧”“手指扶住窗扇，眼睛看向窗外左侧”“剑锋靠近镜头，眼睛在剑锋上方可辨”等具体关系替代“在竹林中很有氛围”。身体、目光、道具可分向，但每个方向应清楚。证据：i-udVnLFcpSu、i-bGEaeYKpvt、i-QbgIWtEAqJ。

写动作停住的瞬间：抬袖可写袖形扬起；举剑可写握持、角度与肩臂张力。不要让单张图承担“转身→看见→拔剑→离开”。来源中的walks、completes a turn等在新作中改成可见瞬间，运镜与时序留给视频。

### 3. 前景是观看位置，不是装饰贴纸

虚竹叶、门框、剑身、乐器与旁人肩影让观众像从环境里看到人物；它们同时提供前中后景和比例。指定遮挡边缘、虚实和人物可见部位。窗扇或枝叶不应恰好挡住主要眼神或手势；若题意是斗笠遮眼，明确以鼻、唇、帽檐与手指承担悬念，不再同时强写双眼清晰。证据：i-3hv4jfutYM、i-9CEYmOhAFW、i-PZZspKIPu2。

### 4. 景别服务情绪，人物优先不等于全是大头

面部近景用于眼神/对峙；胸上或半身保留手和道具；三分之二身可呈现斗笠、衣袖和身体方向。先确定必须入画的动作，再定裁切。近景里不要同时要求完整马身、整座寺庙和全身长袍；双人关系镜宁可放宽一点也要保全触点。i-IbtCYruTOC和i-Ykk78InhCT说明更宽景别也可保持人物主导。

### 5. 柔焦、浅景深、雾和低微反差是不同控制

- 浅景深：决定前后哪些平面清楚；双人镜要让两个主要脸部落在可读范围，不能一张脸清楚、另一张脸无意糊掉。
- 柔焦/扩散：软化明暗过渡与高光边缘；合焦的人物也可柔软，但五官位置、轮廓和关键目光保持可辨。
- 低微反差：降低局部纹理硬度，区别于无结构的磨皮；衣领、发束、手指仍要有层次。
- 空气薄雾：影响空间层次与光传播，不是铺在整张图上的均匀灰色蒙版。

因此避免同时要求“极锐毛孔、刀刻般发丝、强数字锐化”和“低微反差、柔化合焦边缘”。相较旧版的材质强调，本版写自然可辨的皮肤、轻纱/丝绢与湿木反光，颗粒细且克制。多写“soft focus”不会自动更像胶片。

### 6. 冷暖关系围绕人物组织

冷青/墨绿可以是环境底色，红灯、金色日光或木色只占局部，成为脸、手、道具与背景的联系。荷叶灯影把暖光放在胸前灯和脸部，背后的冷湿叶片建立层次；廊下护烛通过双手围住的光表现保护与警觉。日景用自然窗光和暖木色，暮景用金色轮廓与青绿阴影；不要把所有人物涂成青色皮肤。

先指定主光源和受光面，再决定色调。夜景仍须解释脸为何可见；精细反光应对应水、湿叶、灯与金属的实际位置。

### 7. 环境通过接触显得真实

“潮湿”落到贴颊发丝、衣袖重量、荷叶水珠、木面微光等两三处，而不是每句话增加雨雾。衣料厚薄服从季节与身份；薄纱外层可以透光，但不把来源的半透明长袍套给雪庭、战甲或冬装。晴天人物也不必全身湿润。精致、干净、完整的建筑在确定组多次出现，不能统一做成废墟。

### 8. 双人和动物有各自的关系中心

双人先分主动与回应者，写清谁的哪只手接触哪里、彼此视线和距离。簪发、对弈、扶臂分别是照料、试探、协助，不能只复制“两名女子对称站立”。固定白/红只是便于区分角色的来源配色，可换成不冲突的新锚点。人物与动物则明确抱持/抚触位置、相对体型和动物朝向，避免把白狐白虎写成额外发光摆件。

### 9. 幻想程度和历史严谨程度分开选择

本版允许东方幻想的柔化气氛，也能写可信的古代人物。萤火、巨荷、白虎、夸张月亮都是可选内容，不从风格尾巴自动灌进每一张图。冬夜、室内或白昼若无叙事理由，不强加萤火虫；光尘也要有逆光或环境依据。真实历史任务保持原版史实边界；民国旗袍/针织开衫只在相应年代使用，不能作为泛古风衣着。

### 10. “统一胶片”不等于重复所有器材词

用一套连贯的35mm胶片成像语汇足够。35mm在这里主要是胶片画幅/成像气质，不等于所有画面固定35mm焦距。Panaflex＋85mm/f2或50mm/f2.8属于部分探索文案，不是必需参数。原文把35mm film与ARRI Alexa、8K、ultra-detailed混列；新作保留目标成像特征，不用多套媒介和分辨率口号互相竞争。

## 参数如何使用

先分三栏事实：**来源后缀、界面现值、本次建议**。不要把400/25和100/50/5拼成一套，也不能声称提高stylize就是加强柔焦。stylize控制模型审美介入，chaos控制候选多样性，它们都不专门控制古风、颗粒或人物一致性。

可采用以下创作起点，按任务只选一档并在代码块后给五项设置表；这是建议，未经本次重跑验证：

| 用途 | 风格化 | 怪异度 | 多样性 | 取舍 |
| --- | ---: | ---: | ---: | --- |
| 先探索接近来源的气氛 | 400 | 0 | 25 | 风格化/多样性取自常见来源正文，怪异度0是新建议；候选变化可能较大 |
| 已有明确人物与构图，默认创作起点 | 200 | 0 | 5 | 保留胶片气氛，减少不必要变化；不宣称就是来源有效值 |
| 结构、同人延续或手与道具优先 | 50 | 0 | 0 | 沿用半生控制起点；风格靠明确正文和用户选定参考保留 |

当前按已核验的V8.2写 `--ar 16:9 --v 8.2 --raw --s 200 --chaos 5`；画幅按用户要求改变，五项表同步。LibTV有独立滑杆时按format-contract交接。不要自动加入未验证的 `--sref 4029852131 --sv 4`，不要输出翻译过的参数或`--styleze`。用户明确要求复刻该风格码时才单独讨论兼容性与测试，不能预言其视觉效果。

2026-10-12查阅的官方依据：[Version](https://docs.midjourney.com/hc/en-us/articles/32199405667853-Version)确认V8.2及版本兼容性；[Stylize](https://docs.midjourney.com/hc/en-us/articles/32196176868109-Stylize)与[Chaos](https://docs.midjourney.com/hc/en-us/articles/32099348346765-Chaos-Variety)分别解释审美介入与多样性；[Style Reference](https://docs.midjourney.com/hc/en-us/articles/32180011136653-Style-Reference)说明风格引用传递视觉风格，不复制人物/物件。该页对sv的具体说明区分V7/V6，不能据此替本次来源损坏后缀证明V8.2效果。换版本或参数失效时再核验。

## 把新故事转成提示词

1. 选分支：人物情绪/关系为主用本版，空间/人生叙事为主用原版；混合项目逐镜决定。
2. 定人物锚点与唯一情绪任务，明确可见的眼神、手势、衣料和道具。
3. 定景别与观看位置，选一种主构图关系：框中框、前景遮挡、对角剑锋、围绕触点的双人、衣袖与风向等。不要全部用上。
4. 留能支持人物的两三个空间线索，说明前中后景；选一个主光与少量暖/冷辅助。
5. 以35mm胶片、低反差柔焦、微量晕染、轻抬黑位、自然浅景深和细颗粒组成连贯成像块；按日夜与题材删减，不要求每次逐词凑全。
6. 按八项硬格式压成一段中文，参数在尾；默认不额外堆英文。用户要英文MJ时另给同序英文；明确只要英文时遵从。具体例子见 [portrait-templates.md](portrait-templates.md)。
7. 选图先看人物意图、脸/手/道具结构和主次，再看光色；不要因为颜色漂亮而接受手部错误或错位目光。

## 纠偏顺序

| 结果问题 | 优先修改的主因 |
| --- | --- |
| 环境漂亮但人物太小 | 收紧景别，明确主体位置与入画部位，减少建筑全景描述 |
| 变成棚拍古装写真 | 增加明确视线/手势和现场遮挡，让光源、环境与人物发生联系 |
| 全图蒙灰、脸不清楚 | 减少重雾、强扩散、欠曝的叠加；恢复眼神/面部轮廓的可读层次 |
| 过锐、塑料皮肤 | 去掉超细节/HDR/强锐化冲突词，指定自然皮肤与柔和合焦边缘 |
| 人物被道具盖住 | 重新定剑锋/帽檐/叶片与眼线关系；保留有意遮挡的叙事目的 |
| 双人融合或手数错误 | 减少交叉肢体，指定单一接触点及各自左右手，必要时放宽景别 |
| 只有换名没有新故事 | 重写人物意图、接触对象、观看位置和情绪，不只替换衣色或地点 |
| 一组人物都变脸 | 先选人物锚点，再用当前模型可用参考/编辑方式；不依赖相同seed或一串“同一人” |

纠偏每次优先一个主因。废片组只提供可能的风险方向，不能在没有对照生成时认定某参数或某个词是失败原因。仅学这版图片提示词时不强制输出视频；需要视频再实际看图并回到半生六段式。原文中的单段5秒Kling 3.0写法作为资料保留，不覆盖既有交付格式与模型选择。
