# Seedance 2.5 出片分支

本文件是半生·增强版的第二条视频分支。默认仍为Kling O3单镜头六段式；只有用户选择Seedance 2.5，或本段镜头符合下方选择条件并由用户确认采用时，才读取并按本文件交付。两条分支不能混写在同一个代码块里。

## 能力边界（只引用适配器已写明的内容）

- 来源：洋子库 film-cinedance 的 seedance-25-prompt-format.md（引用 ByteDance Seed 官方2.5发布资料）：单次生成最长30秒，支持后续延长；单次最多参考30张图片、10段视频、10段音频，总计50个多模态素材；支持多镜头长叙事、参考视频、时间戳控制和局部编辑。
- 这些是官方模型能力，不是用户所用入口的保证。即梦、LibTV或其他第三方界面的实际可选时长、画幅、清晰度、参考槽位数与音频开关，**一律以用户界面为准**。黑木崖画布面板曾显示“2.5、图片参考、16:9、720P、10s”，只是该节点的面板现值，不作为本技能默认值。
- 不编造上述以外的上限、参数名或按钮名称；界面没有某项功能时，标明“界面未提供”并改写方案。

## 选择可灵O3还是Seedance 2.5

| 本段镜头特征 | 采用 |
| --- | --- |
| 单镜头、一个主要事件、以一张已选图作首帧图生视频；全景环境微动、单人一个明确动作、近景眼神呼吸 | **Kling O3**（默认，六段式不变） |
| 一段内需要2个以上连续镜头/切镜的攻防节拍或“动作→反应→后果”三拍 | **Seedance 2.5** |
| 有准确对白、双人对话或需要声画同步的台词段 | **Seedance 2.5**（Kling也可做单句台词，按用户选择） |
| 需要同时用多张参考图分别锁定人物身份、服装、场景空间或道具 | **Seedance 2.5** |
| 用户明确指定平台 | 按用户指定，不因内容自行改换 |

判断后用一句话说明“本段走Kling单镜/走Seedance连续段及原因”。符合Seedance条件但用户未说平台时，可默认先给Kling拆镜方案并提示“此段也适合Seedance连续段”，由用户决定；用户已选Seedance则直接交付。

## Seedance硬格式：一个代码块、严格六段、标签固定

每段一段文字，段间恰好一个空行。标签逐字一致，不加粗、不编号、不换同义词，不增加第七段。

```text
总控：[总秒数]秒连续段落，[画幅]，[镜头数]个镜头，真人实拍质感的中国古代历史电影；[时代与视觉分支一句]；[声音方式一句]

参考素材：@Image1｜图片｜身份与服装｜保留：[脸、发式、服装版本与颜色]｜不影响：[场景构图、运镜]；@Image2｜图片｜场景空间与材质｜保留：[门窗、结构、主光方向]｜不影响：[人物身份]

首帧状态：[人物名＋可见识别特征、世界位置、朝向、姿势、手与道具状态、场景、主光源和轴线]

时间轴：0.00–[终点]秒 S01：机位[景别/运镜]；动作[可见动作与表演]；对白[人物名：“准确台词”或无]；结束[结束状态]；[下一起点]–[终点]秒 S02：……；[最后起点]–[总秒数]秒 S0N：……结束[可剪尾帧]

声音：[对白声线/环境音/旁白方案]；不生成BGM

否定控制：[针对本段的换脸、服装漂移、道具结构、空间几何、天气方向等失误]；无字幕、无Logo和水印
```

### 各段硬规则

1. **总控**：总秒数为数字，且与时间轴终点相同；不超过30秒，同时不超过用户界面可选时长。画幅与参考首帧/主场景图一致，默认16:9。必须保留“真人实拍质感”“古代历史电影”的半生影像底色；人物胶片分支可加“柔和胶片成像”，不叠加另一套锐度词。
2. **参考素材**：只列实际上传的素材，标签与界面实际标签一致（平台若显示“图片1”就写图片1）。每个素材**一个职责**，写清“保留”与“不影响”。有角色锚点卡时，主角定妆近景必须作为一条参考，职责写“身份与服装”。职责冲突时拆成两张素材或请用户选择；不写虚构素材编号。没有参考素材时写“参考素材：无”。
3. **首帧状态**：写全可见的完整物理状态。若有首帧图，只继承看得见的内容；未看图时整段标为预案。
4. **时间轴**：从`0.00`起两位小数连续覆盖到总秒数，不重叠、不留空档。每个时间段写镜号＋机位＋动作＋对白＋结束状态五项。切镜时完整写出新机位中的人物位置与身体状态，不写“同上”“继续上一镜”。动作主体用人物名＋一个可见识别特征，不用孤立的@Image1充当动作主体。角色锚点句的身份描述在本段首次出现人物时原样写入。
5. **对白容量**：对白逐字照用户稿，不改写。按适配器经验：30秒几乎全为自然说话时约72–84个有效汉字；有动作、停顿、听者反应时先扣除。装不下就拆段或请用户决定删改，禁止加快语速硬塞。
6. **声音**：单列一段（这是与Kling版的结构区别：Kling声音写在情节段内）。默认不生成BGM；有台词时不能写“无声”。
7. **否定控制**：只写本段主要失误，不堆通用负面长串。

### 半生影像在Seedance中的保持

- 吸收黑木崖2.5稿的有效结构：开头约2秒直接进入正在发生的动作，不从静止参考图缓慢推近；约第5秒给第一处高潮；交锋写清攻守因果与手位距离；爆点局部、主体建筑稳定；结尾短暂情绪停顿给剪辑落点。
- 不照搬黑木崖“具体招式交给模型自由发挥”“港式奇幻”的写法作为默认；半生以人物经历和可信表演为主，动作强度服从剧情。
- 每段镜头数随内容决定，30秒只是上限。时代、服饰、器物仍按半生规则查库与考据边界处理。

## 交付形式

每段交付：“对应镜号/首帧与参考图编号及可见锚点 → Seedance 2.5提示词（一个代码块）→ 参数建议（时长、画幅、参考素材清单、声音开关）→ 用户操作”。最终匹配版必须已实际看过首帧/参考图；否则标“预案，待成图校准”，格式同样完整。
