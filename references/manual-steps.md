# 手动生成交接

此技能只提供提示词和操作指导。平台说明按各节注明的日期保存，未另标注的部分为2026-09-30本地快照，默认无需联网即可使用；实际界面有变化时，以用户显示的名称和选项为准。需要最新兼容性时再核验官方资料，不能猜按钮或模型别名。

## MJ生图阶段

给用户的步骤应包含本轮真实镜头编号与提示词，不原样照搬空模板：

1. 到MJ网页的Create／Imagine输入区，先粘贴角色关键近景或首个叙事镜头的完整提示词。正文与参数是一个输入；不要把中文说明标题一并粘贴。
2. 确认当前使用的版本。V8.2快照的写实起点是`--ar 16:9 --v 8.2 --raw --s 50 --chaos 0`；其他画幅替换`--ar`。这组数值是本技能的创作起点，不是平台官方推荐配方。
3. 先出一批候选，选叙事信息完整、脸/手/道具结构正常且方便运动的一张。不要为了色彩漂亮选动作无法执行的图；手中的剑、杯、竹杖必须与剧本对应。
4. 先锁定主角关键图。后续镜头引用这张图做角色参考；跨年龄时保留鼻梁、眼间距、脸骨等身份锚点，改变年龄与风霜。V8.2的Edit Model可承接人物参考和编辑，不使用旧版本的角色参数来假装锁脸。
5. 在网页可用的Edit／Quick Edit／参考图输入中放入选定图，再粘贴本轮给出的编辑或新镜头提示词。Style Reference主要约束视觉风格，不等于角色身份证；相同seed也不能保证人物同脸。
6. 选定后下载完整单图，按`S01`、`S02`等镜号区分，把完整图或可访问的图片附件发回并写明镜号。需要选图比较时可以回传候选组；最终首帧应是单图，不是四宫格或界面截图。

原文中的“保持原图，只改帽子/衣色/黑边”适用于已选图的编辑阶段。给单一改动，再写需要保留的构图、脸、服装、背景与光线；不要因一个帽子问题重新改变全图。

不要宣称提示词中的8K是实际分辨率。画面构图和内容确认后，再按用户界面可用的HD或放大功能处理。

## LibTV图片的五项设置交接

2026-10-08实际读取《奉天靖难》画布的Style Image V8.2图片节点，额外的三个数值设置分别叫“风格化程度”“怪异度”“多样性”。加上画幅和版本，共给用户五项本镜建议；不是五个额外滑杆。

1. 每条图片提示词代码块外另给五行表：画幅、版本、风格化程度、怪异度、多样性（随机性）。每镜填写具体值；全部沿用上一镜时也完整列出。
2. 用户在LibTV粘贴中文画面正文，后缀中的MJ参数不必一并放入正文；在模型/画幅与高级设置中按表设置。风格化对应`--s`，多样性对应`--chaos`；怪异度单独给数值，不把它混成风格化或seed。
3. 原项目节点i-pq5454uvj3sd的提示词后缀写风格化200、多样性5；面板却显示风格化100、怪异度50、多样性5。两者都是本次读到的事实，但不能确定实际成图采用谁、谁覆盖谁。来源记录分别保存；新交付只给一组建议，正文后缀与表格一致。
4. 通用写实连续性起点是风格化50、怪异度0、多样性0；宫阙风格探索可从200、0、5开始。这些是创作建议，未经本轮实际生图验证，也不是原作有效生成设置的断言。故事强调准确人物/道具时优先降低变化，不能为追求风格自动提高怪异度。
5. 实际界面若没有某个选项，应标明“不适用/界面未提供”并按用户所用模型重新适配；不把LibTV字段名当成所有模型通用参数。当前脚本针对有这三项数值设置的MJ/Style Image交付，不用于不兼容模型。

## 选图回传后

先指出这张图能否承担该镜：人物姿态、手与道具、运镜空间、主光和主体位置。存在关键结构问题时，给一段针对问题的编辑提示词和需要保留的项目；结构合格才进入最终视频提示词。

用户只发文字描述或文件名时可以写预案，但应标“待实际成图校准”。实际观察图像的步骤不能被模板或预案替代。

## Kling O3图生视频阶段

本项目的LibTV视频节点实际显示`Kling O3`、`图生视频`；示例v-aoyev3qdtH显示16:9、4s、1个。项目UI名称是本技能默认目标；不能因为官方文档用VIDEO 3.0 Omni名称，就断言任何第三方“O3”都完全等价或具有相同选项。

### 在LibTV项目中

1. 使用本轮选定的`Sxx`图片建立或选择图片节点。在视频节点的模型栏选择实际显示的`Kling O3`，模式选`图生视频`。
2. 将该图片作为起始画面／首帧输入。项目可通过图片节点连接视频节点引用素材；连接后检查该图的输入用途，普通参考图不能自动等同首帧。若看不清用途，先让用户确认界面中的首帧位置。
3. 将本轮完整六段提示词粘贴到视频提示词框。若已连接文本节点，检查最终输入内容，避免文本节点和编辑框把同一提示词重复注入。
4. 画幅与选定图一致，时长与时间轴一致。界面无法选建议秒数时，选择可用时长，并先让技能按该时长重写时间轴；不要用6秒设置跑8秒台词提示词。
5. 每镜按单镜头生成；智能分镜/多镜头功能若有则关闭，除非本轮明确设计多镜头。文字“单镜头”与实际功能设置应一致。
6. 有音频开关时，按本轮台词/环境音方案设置。无音频入口或模型不支持时，保留视觉表演，将声音说明改作后期配音/音效清单。不能宣称文本必然让模型输出声音。
7. 建议先以1条验证关键镜头，再由用户决定其他镜头的提交数量。点击生成和额度消耗由用户完成，技能不代点、不排队、不替用户付费。
8. 检查生成片开头是否承接首帧，中段主动作是否完成，结尾是否可剪；重点看脸、手、衣服、兵器/马匹、背景几何和雨雪火焰方向。遇到问题回传视频或关键帧及镜号，再改对应镜。

### 在可灵官方界面中

让用户选择界面实际提供、与目标匹配的模型及Image-to-Video／图生视频入口，上传到首帧位置，粘贴提示词，再设置可用时长、画幅和声音。若没有`O3`名称，不编造下拉选项，也不自动替换成O1/2.6/3.0；先核对用户界面中的模型名称和支持功能，再适配说明。

## 角色锚点卡定妆图（增强版）

分镜图之前先生成定妆近景：粘贴锚点卡给出的定妆提示词，按五行表设置，选脸、发式、服装与道具都清楚的一张，按`A01-角色名`命名回传。之后每镜在MJ的Edit/参考图入口放入该图，再粘贴分镜提示词。

## Seedance 2.5生视频阶段（增强版）

入口可能是即梦、LibTV或其他接入2.5的界面；按钮与选项名称以用户界面实际显示为准，这里不假定任何按钮名。

1. 在界面中选择实际显示的Seedance 2.5模型（没有2.5字样时先让用户确认模型名，不自行替换为其他版本）。
2. 按提示词“参考素材”段的顺序上传素材，确认界面给每张图的标签与提示词中的@Image编号一致；不一致时以界面标签为准，让技能改写提示词。定妆近景放在“身份与服装”那一条。
3. 若界面区分首帧与普通参考，把“首帧状态”对应的选定图放到首帧位置；只有参考入口时，说明不能保证它被当作首帧。
4. 粘贴完整六段提示词。时长选与`总控`一致的秒数；界面没有该秒数时选可用时长，先让技能按新时长重写时间轴。画幅与首帧/主场景图一致。
5. 有台词时打开声音/音频生成（若界面提供）；没有音频功能时把对白改作后期配音清单。
6. 先生成1条验证；点生成和消耗额度由用户完成。回传视频或关键帧并标段号，按generation-feedback回填后再修。

## 本地保存的官方资料要点

以下是必要能力快照的简短整理，外链仅供需要更新时核验，不是日常使用依赖：

- [MJ Version](https://docs.midjourney.com/hc/en-us/articles/32199405667853-Version)：2026-09-30读取时默认V8.2；V8.2使用Edit Model承接原Omni/Character Reference功能。V8.2兼容表不支持`--q`、旧Omni参数或多提示词权重。
- [MJ Parameter List](https://docs.midjourney.com/hc/en-us/articles/32859204029709-Parameter-List)：参数放正文末尾，使用`--ar`、`--v`、`--raw`、`--s`、`--chaos`等有明确含义的参数，避免混入其他版本选项。
- [MJ Edit Model](https://docs.midjourney.com/hc/en-us/articles/48495453462797-Edit-Model)：V8.1/V8.2的编辑与多参考图功能；网页可从Imagine的图片入口、Quick Edit或Editor使用。适用参考图最多四张；这不是同脸保证。
- [Kling VIDEO 3.0 Omni Guide](https://kling.ai/quickstart/klingai-video-3-omni-model-user-guide)：官方模型支持图生视频、首尾帧与参考输入，并介绍声音和镜头控制。第三方LibTV的模型映射、额度与选项仍以其界面为准。
